PHONE + CLOUDFLARE PAGES
1. Open Cloudflare Dashboard in Chrome.
2. Go to Workers & Pages.
3. Choose Create application > Pages > Direct Upload / Drag and drop.
4. Create a project, e.g. fuel-shift-demo.
5. Upload this ZIP.
6. Deploy site.
7. Open the resulting *.pages.dev address on your phone.

The demo stores test changes in browser localStorage only.
